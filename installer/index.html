What's Inside

Everything you need to stream,
nothing you don't.

Built from the ground up with Rust and Tauri — no Electron bloat, no JVM, no compromises.

⚡
Sub-200ms Launch
Native Rust backend with embedded SQLite launches faster than any Electron or JVM-based alternative.
🧩
CloudStream Plugin Engine
Install and run .cs3 plugins from any GitHub-hosted repo.json URL with one click.
🛡️
M3U8 CDN Bypass Proxy
Built-in local proxy on 127.0.0.1 injects Referer, User-Agent, and Origin headers to defeat 403 CDN blocks automatically.
⏩
AniSkip Integration
Auto-detects anime intro/outro timestamps from AniSkip API and shows a one-click "Skip Opening" button.
💬
Multi-Language Subtitles
Automatically searches OpenSubtitles and Subsource for subtitles in your language with zero configuration.
📖
Watch History & Resume
Embedded SQLite tracks your exact playback position across all shows and movies — always resume where you left off.
🌐
BDIX Gigabit FTPs
Native providers for CircleFTP, SamOnline, and DiscoveryFTP give Bangladesh users gigabit-speed domestic streams.
⌨️
Keyboard-First Navigation
Full shortcuts: Space/K, J/L seek, F/F11 fullscreen, M mute, Alt+1–5 for instant tab switching.
🎨
Cinema-Grade Dark UI
Glassmorphism design with glowing cyan/purple/emerald accents and smooth 60fps micro-animations throughout.
Get Started

Install in minutes.

Choose your installation method. The wizard handles everything automatically.

1
Download the Installer
Click the download button to get CloudStream-Desktop-Setup.exe for Windows 10/11.
~25 MB · No extra dependencies
2
Run the NSIS Installer
Double-click the .exe and follow the setup wizard. WebView2 and libmpv are bundled — nothing else to install.
3
Add a CloudStream Repository
Open Extensions (Alt+4) → Add Repository → paste a repo.json URL:
https://raw.githubusercontent.com/nehalDIU/nehal-CloudStream/master/repo.json
4
Install Extensions & Stream 🎉
Browse the extension catalog, install .cs3 plugins with one click, then search and stream your content.
🎬 You're ready to stream!
🛠️ Build from Source
Requires Node.js 18+ & Rust toolchain.
git clone https://github.com/sheikhshariarnehal/CloudStream-Desktop
cd CloudStream-Desktop && npm install
npm run tauri dev # development
npm run tauri build # build .exe installer
💡 Pro Tips
• Alt+4 opens the Extension Manager
• F11 toggles cinema fullscreen mode
• The M3U8 proxy starts automatically — no config needed
• .cs3 plugins are stored in %APPDATA%/cloudstream
